# Autovisa

HTML-pohjainen autovisa, joka käyttää Azure Functionsia ja Azure Blob Storagea kuvan generointiin.

## Käyttöönotto

1. Lisää `PIXABAY_API_KEY` ja `AZURE_STORAGE_CONNECTION_STRING` Azure Functions Appin asetuksiin
2. Tee `images`-säilö julkiseksi Azure Blob Storage -tilille
3. Julkaise tämä projekti Azure Static Web Appina (GitHubista)
